## LAB02: Data Preprocessing

* **Part 1: Dataset Exploration** – Exploring data dimensions, verifying variable types, and detecting missing values or duplicate records.  
* **Part 2: Data Visualization** – Plotting histograms to analyze sales distributions and creating correlation heatmaps to visualize relationships between numerical variables.  
* **Part 3: Data Cleaning** – Removing duplicate data, handling missing values in the `Year` column using the Median, and filling missing values in the `Publisher` column using the Mode.  
* **Part 4: Feature Engineering** – Converting categorical text data into numbers by applying **Label Encoding** to game genres (`Genre`) and **One-Hot Encoding** to gaming platforms (`Platform`).
