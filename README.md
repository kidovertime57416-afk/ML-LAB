# Machine Learning

This project is a collection of laboratory assignments and homework for the Machine Learning course, implemented using Python

- [LAB07 - CNN](LAB07%20-%20CNN/README.md): จำแนกภาพ Lion/tiger ด้วย CNN
- [LAB08 - DCNN](LAB08%20-%20DCNN/README.md): ใช้ dataset เดิมจาก LAB07 ทดลอง VGG แบบย่อ เปรียบเทียบโครงสร้างและจำนวน epochs
- [LAB09 - Object Detection I](LAB09%20-%20Object%20Detection%20I/README.md): ทดลองจำแนกภาพ crop แบบ R-CNN และ Fast R-CNN
- [LAB10 - Object Detection II](LAB10-Object%20Detection%20II/README.md): ตรวจจับสัตว์น้ำ 7 คลาสจาก Aquarium dataset ด้วย YOLOv8n
